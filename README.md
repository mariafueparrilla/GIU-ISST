# GIU – Gestor de Incidencias Urbanas

Proyecto de la asignatura Ingeniería de Sistemas y Servicios Telemáticos (ISST).
Grupo 09.

## Sprint 1 (objetivo)
- Proyecto Spring Boot inicial
- Estructura base del backend
- Configuración de base de datos en desarrollo (H2)

## Tecnologías
- Java 17
- Spring Boot
- Spring Web, Spring Data JPA
- Thymeleaf
- H2 (desarrollo)

## Cómo ejecutar
Windows:
mvnw.cmd spring-boot:run

Luego abrir:
http://localhost:8080
